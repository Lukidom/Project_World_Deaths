# Deaths of World Program 

A Python program that tracks and plots global deaths over a 10-year period (2010-2019) from a CSV data file.

## Description

This program (`deaths_of_world.py`) reads data from a CSV file (`deaths_of_world.csv`), validates the data, filters and sorts it, and creates visualizations to answer key questions about global mortality trends.

[Youtube](https://youtu.be/AWnDecfO5KM)

### Questions Answered

1. **What countries have the highest death rates?**
2. **How have death rates increased across the years?**

## Features

- **Data Validation**: Checks CSV file integrity
- **Error Handling**: Full error handling 
- **Year Filtering**: Separates the last 10 years of data (2010-2019)
- ** Analysis**: Two sorting functions to answer each research question
- **Data Visualization**: Two separate graph plotting functions


## Usage

Integrated Terminal Command
```bash
python project_death/deaths_of_world.py
```

The program will:
1. Load and validate the CSV data
2. Filter data for years 2010-2019
3. Display the top 15 countries by total deaths
4. Plot visualizations for both research questions
